# Mental Math Pro

I built this little project to practice fast mental math. The main inspiration was Zetamac, but I wanted something with a few more options and a game mode that induces a bit more anxiety (in a good way). 

Besides the four basic operations, I added fraction-to-decimal conversions and simple decimal math, which always come in handy.

## The Modes

*   **⏱️ Sprint (2 Minutes):** The classic. How many questions can you solve in 120 seconds?
*   **🏃 Marathon:** You have a fixed goal of 80 questions to complete as fast as possible (with an 8-minute cap so you don't go crazy).
*   **🔥 Survival:** My personal favorite. You start with just 20 seconds on the clock. Correct answers give you +2 seconds, but mistakes cost you -3 seconds. The goal is to survive as long as possible without the timer hitting zero.

## How to use

There's nothing to install or build. It's all in a single file.
Just clone the repo (or download the zip) and open `index.html` directly in your browser.

## Stack 

Keeping it simple:
*   HTML / Vanilla JS (no frameworks, keeping the input as responsive as possible).
*   Tailwind CSS (included via CDN, just so it doesn't look like a 90s website).

Feel free to fork it or open a PR if you want to add more operations!
